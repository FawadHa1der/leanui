The race one app, three ways, side by side

Each panel runs the same app: written by hand in JavaScript, written in Lean and compiled to WebAssembly (wasm64, LeanUI's production build), and the same Lean program run by lean-vir, Lean's interpreter compiled to WebAssembly. This page clicks each app's own buttons, times every click, and checks that all three end up showing the same thing.

How it is measured. Script time is the time the clicks take: the app's own work (for LeanUI, the Lean update, view and diff) and its DOM calls. Style, layout and paint come later, once per frame, for the same DOM in all three, and are not counted. In Life, the panels take turns: each gets 8 ms of clicks per animation frame, so in the same time the faster ones get further. Table runs the standard operations one panel at a time, each after its usual warm-up clicks; the median of the runs counts. “Started in” is the time from loading the panel to the app being ready, with the compressed size of what it downloaded. The first run also pays for the browser compiling the WebAssembly. The automated benchmarks behind these numbers are in docs/BENCHMARKS.md.
